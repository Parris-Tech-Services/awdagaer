# SIGNAL BENEATH — The Parris Quilt

A browser-first text RPG that stitches Josh Parris's games, apps, infrastructure experiments, archives and real troubleshooting stories into one interconnected universe.

## Play

https://parris-tech-services.github.io/awdagaer/

## Current playable build

- Branching interactive-fiction opening and Act I finale
- Persistent local save
- Watchful, Practical, Steady, Curious, Discernment, Integrity, Family Connection, Stability and Tech Debt systems
- DadLAN, Archive, NeathBound, DBO1-SIM, Home, Chemist and Workbench story locations
- 50 recovered conversation threads in the journal
- Project Quilt / Constellation linking public games, apps and tools across the Parris project ecosystem
- Direct playable links for verified live games where available
- Four first-pass endings: Preserve, Federate, Disconnect and Local

Private repositories are deliberately not published into the public Project Quilt. This is a living hub: future public projects can become new Quilt nodes and story portals rather than isolated apps.
